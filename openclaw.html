Background

What the open-source community figured out

Before hosted assistants arrived, an open-source project let anyone run a personal AI agent on their own hardware. Its community learned a lot — and most of it is still the best advice for using any assistant well.

A short history

OpenClaw is a free, open-source personal AI agent released under the MIT license. It was created by Peter Steinberger, the founder of PSPDFKit. It first appeared in November 2025 under the name Clawdbot. After Anthropic raised a trademark concern — "Clawd" sat too close to "Claude" — the project became OpenClaw on January 30, 2026. It went on to become one of the fastest-growing open-source projects of its kind, collecting tens of thousands of GitHub stars in its first months.

The idea is simple to state: instead of renting an assistant from a company, you install one on your own machine or server, and it acts for you — reading files, running commands, browsing the web, and working across the services you connect.

How it works

OpenClaw runs locally, on hardware you control. You bring your own model: it works with Anthropic's Claude, OpenAI's GPT models, and local models through Ollama. It does not replace those models; it gives them hands — file access, a shell, a browser, and tools — behind one interface.

A single background process, the gateway, routes messages from the chat apps you already use. OpenClaw connects to more than twenty platforms, including WhatsApp, Telegram, Discord, Slack, Signal, and iMessage. A heartbeat daemon lets the agent act autonomously on a schedule — a morning briefing, an inbox sweep, a standing check — without waiting to be asked.

The file insight

The part of OpenClaw that matters most is also the plainest. Everything about the agent lives in ordinary text files:

  • SOUL.md — the agent's personality, mission, and hard rules
  • AGENTS.md — coordination rules and standard operating procedures
  • IDENTITY.md — the agent's detailed persona
  • USER.md — what the agent knows about its person
  • MEMORY.md — long-term memory, with daily logs beneath it
  • SKILL.md files — reusable skills that extend what the agent can do

Because all of it is Markdown and YAML, everything is readable, diffable, and version-controllable. You can open your agent's soul in a text editor and change a sentence. OpenClaw also standardized the SKILL.md format and runs ClawHub, a community marketplace where skills are security-scanned before people install them. Its community even maintains public template libraries — hundreds of ready-made SOUL.md configurations you can copy and adjust.

The trade-off

Ownership cuts both ways. With OpenClaw you control where your agent runs, which model powers it, and what it can touch. You also own the setup, the API costs, and the security. That last part is real work. After a 2026 change, OpenClaw tool permissions are disabled by default and have to be explicitly allowlisted; people who missed the release notes watched their agents "suddenly become dumb" and blamed the model. The model had not changed — the tools were off.

That small episode carries the main lesson: an agent's power comes from its permissions, so permissions deserve the same care as the model choice.

The hosted answer

Muse, Meta's personal AI agent (launched September 8, 2026, in the US and Canada, with a free tier and paid plans), takes the same file-based idea and hosts it: each person gets a dedicated computer, and the agent's identity, memory, and skills live in plain files, with the standing infrastructure handled for you. The safety layer is built in rather than configured — a Secure Vault that stores sign-in details entered through the app's own secure screens, so the agent can sign in without ever seeing the values, and approval cards that ask before sensitive actions like purchases or sending email.

Same soul files, less yak shaving. DIY dieselpunk on one side, hosted on the other — and the underlying insight, that an agent should be a set of files you can read and edit, belongs to the open-source community that proved it first.
